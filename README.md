# CS2 Upgrade (ورود با استیم، بدون API Key)

بازی مجازی با سکه‌ی فرضی. ورود با Steam OpenID، و ذخیره‌ی سکه و انبار هر کاربر روی سرور.
کلید API استیم لازم نیست؛ اسم و عکس از پروفایل عمومی گرفته می‌شود (پروفایل خصوصی = اسم پیش‌فرض).

## اجرا روی کامپیوتر
1. Node.js نسخه ۲۰ یا بالاتر.
2. `.env.example` را کپی کن به `.env` و مقدار `SESSION_SECRET` را پر کن.
3. `npm install` و بعد `npm run dev`
4. باز کن: http://localhost:3000

## گذاشتن روی GitHub و دیپلوی
GitHub Pages بک‌اند را اجرا نمی‌کند. کد را روی GitHub بگذار و روی Render یا Railway از ریپو دیپلوی کن:
- Build Command: `npm install` — Start Command: `npm start`
- Environment: `SESSION_SECRET` و `BASE_URL` (آدرس https سایتت، مثلاً https://نام-تو.onrender.com)

## نکته‌ها
- `BASE_URL` باید دقیقاً همان آدرسی باشد که کاربر در مرورگر می‌بیند، وگرنه ورود استیم برنمی‌گردد.
- `data.json` روی هاست رایگان با ری‌استارت پاک می‌شود. برای ماندگاری Disk یا دیتابیس بگیر.
- منطق بازی داخل مرورگر اجرا می‌شود و کاربر آگاه می‌تواند سکه‌اش را دستکاری کند.
